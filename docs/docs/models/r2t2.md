## 🧩 Model Card: [r2t2:1.7b](https://huggingface.co/netease-youdao/Confucius4-R2T2)

- **Type:** Speech-to-Text (ASR: Automatic Speech Recognition)
- **Think:** No
- **Tool Calling Support:** No
- **Base Model:** [netease-youdao/Confucius4-R2T2](https://huggingface.co/netease-youdao/Confucius4-R2T2) (fine-tuned from [Qwen/Qwen3-ASR-1.7B](https://huggingface.co/Qwen/Qwen3-ASR-1.7B))
- **Parameters:** 2B (0.3B audio encoder + 1.7B text decoder)
- **Quantization:** decoder Q8_0, audio encoder BF16
- **Languages:** 30 (best at Chinese and English)
- **Max / Default Context Length:** 8k tokens, about 10 minutes of audio (12.5 audio tokens per second)

Confucius4-R2T2 ("Real Real-Time Transcription") is NetEase Youdao's speech recognition model, trained for true streaming: it can transcribe while the speaker is still talking and never edits text it has already written. FastFlowLM currently runs it on **whole audio files**; the streaming mode is not exposed yet.

▶️ Run with FastFlowLM in PowerShell:

```shell
flm run r2t2:1.7b
```

Then, type (replace `audio.wav` with your audio file path; wav, flac, mp3 and ogg are supported, any sample rate or channel count):

```shell
/input "path\to\audio.wav"
```

Text after the file name is used as **context / hot words** for the model (names, terms, topic):

```shell
/input "path\to\meeting.wav" Acme, Zhang Wei, quarterly roadmap
```

### Server Mode

```shell
flm serve r2t2:1.7b
curl http://localhost:52625/v1/audio/transcriptions \
  -F file=@audio.wav -F model=r2t2:1.7b
```

The OpenAI-compatible `v1/audio/transcriptions` endpoint accepts `response_format` = `json`, `text`, `verbose_json`, `srt` or `vtt`, `language` (for example `English` or `Chinese`; empty = automatic detection) and `prompt` (context / hot words). Requesting `r2t2:1.7b` loads it as the server's model; any other `model` name is served by the Whisper sidecar (`--asr 1`) as before. Audio that cannot be decoded or does not fit in the context window is answered with HTTP 400.

> The `srt` / `vtt` / `verbose_json` formats carry one segment for the whole file; R2T2 does not produce word timestamps.

### Smoke test

The sample clip of the model's repository ([test.wav](https://github.com/netease-youdao/Confucius4-R2T2/raw/master/resources/test.wav), 6.7 s of Mandarin) must give:

```
之前有顾客自己带酒水，也没加收钱或者不让喝。
```

### Notes

- Every request is its own transcription: nothing is kept between requests.
- The model reports a language (shown as `language` in `verbose_json`); for some Mandarin clips it reports none, which is normal.
- Long recordings are fine up to the context window (about 10 minutes at the default 8k tokens).
- Memory: about 5 GB after load and 7 GB while transcribing a minute-long recording (the audio encoder and the prompt processing run on the CPU, the decoder on the NPU).
